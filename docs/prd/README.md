# PickAus 需求文档目录

开发以两份 PRD 为准，按页面写，每页都含界面上看不见的规则。

- 小程序：`docs/小程序需求文档.md`
- 网页管理后台：`docs/管理后台需求文档.md`

订单状态、库存、退款两边是同一套，不要各写各的。原型在 `prototype/miniprogram` 和 `prototype/admin`。

下面只标这次改动落在哪一页，规则仍以那两份为准：

- 线下配送选日期和时段：小程序 4.8、8.1，后台第 10 节。日期从明天起 7 天。时段是后台配置的钟点。
- 收货地址必须点选地图检索结果：小程序 4.7。
- 填写手机号的地方固定带 `+61`：小程序 4.7、6.4、7.3。
- 商城和闲置列表是瀑布流。商城只有点赞，没有评价：小程序 4.1、4.5，后台第 8 节。
- 闲置联系方式：拒绝这一次后可以再申请；「拒绝此人」之后不能再申请这条。小程序 6.2、6.3，后台第 13 节。
- 后台闲置是封面墙。任一管理员打开详情记「已浏览」，卖家改内容后清掉。后台第 12、13 节，小程序 6.2 的编辑。
- 游客可浏览。微信登录只认 openid 和 unionid，然后再绑澳洲手机号。小程序 3.1、7.1、7.5、7.6。
